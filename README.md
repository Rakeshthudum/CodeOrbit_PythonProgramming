CodeOrbit Python Programming Internship

This repository contains the projects completed as part of the **Python Programming Internship at CodeOrbit Technologies**.

Projects:
1. Simple Calculator
A command-line calculator developed using Python.
Features:
* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Invalid input handling
File: `Simple_Calculator/calculator.py`


2. Number Guessing Game
A command-line game in which the program generates a random number between 1 and 100 and the user attempts to guess it.
Features:
* Random number generation
* Too High and Too Low hints
* Attempt counter
* Invalid input handling
* Option to play multiple rounds
File: `Number_Guessing_Game/guess_game.py`

3. To-Do List CLI App
A command-line application for managing tasks using a Python list.
Features:
* Add tasks
* View tasks
* Remove tasks
* Numbered task display
* Invalid input handling
* Menu-driven interface
File: `To_Do_List/todo.py`

Technologies Used
* Python 3
* Command-Line Interface
* Python Standard Library
